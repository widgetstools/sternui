Client wasm sharing

Every blotter window imports the 5,070 kB inline build, including the server wasm it never runs — roughly 900 ms of each window’s ~1.1 s open. This asks whether the compiled client module can be obtained in a SharedWorker and shared, and measures each candidate strategy by the only thing that settles it: a row count read from the worker-held Table, and the bytes that window actually fetched.
