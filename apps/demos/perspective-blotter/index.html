Perspective pull path — live STOMP feed

One SharedWorker holds the STOMP connection and one Perspective Table; every window opens a View against it and reads only the rows its viewport asks for. The claim under test is that the 2nd and 3rd blotter open as fast as the 1st, because only the first pays for the 18-second snapshot. MarketsGrid mounts the real widget — toolbar, customizer, column defs — on the same worker-held Table; raw AG Grid is the minimal reference.

Needs the broker: cd apps/demos/stomp-view-server && npm start
